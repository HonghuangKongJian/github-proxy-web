GitHub 加速下载

粘贴 GitHub 链接，生成一条带签名的高速通道。链接含随机校验码，无法批量伪造。

支持仓库、Release 附件、raw 文件、gist、仓库 zip/tar 包

生成成功

命令行也能用

生成后的链接可直接用于 git clone，无需额外配置：

git clone https://你的域名/p/xxxxx.xxxxxxxx.xxxxxxxxxxxxxx/https://github.com/user/repo.git

想让所有 GitHub 地址自动走这条通道，把生成好的链接前缀写进全局配置：

git config --global url."https://你的域名/p/xxxxx.xxxxxxxx.xxxxxxxxxxxxxx/https://github.com/".insteadOf "https://github.com/"

链接过期后重新生成一条即可，原来的链接会失效。

关于随机码

  • 每条链接由服务端签名生成，含一次性随机码，无法猜测或批量拼凑。
  • 链接有有效期，过期自动作废，历史链接不会被长期盗刷。
  • 生成时浏览器会做一次轻量计算（约 1 秒），用于阻挡脚本批量刷取。
